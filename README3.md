AI Recommendation Logic

Project Overview

This project creates a simple recommendation system based on user preferences and interests.

Features

- Takes user interests as input.
- Matches preferences with available courses.
- Calculates a match score.
- Displays recommended courses based on matching interests.

Technologies Used

- Python
- Conditional logic
- Lists and dictionaries
- String matching

How to Run

1. Download or clone the repository.
2. Open the terminal in the project folder.
3. Run the following command:

python project3.py

4. Enter your interests when prompted.
5. View the recommended courses.

Learning Outcomes

- Understanding recommendation systems.
- Practicing logic building and pattern matching.
- Learning how to calculate preference match scores.
