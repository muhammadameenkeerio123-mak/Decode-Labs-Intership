Data Classification Using AI 🤖

DecodeLabs Internship — Project 2 (2026)

A Python machine learning project that classifies Iris flowers using supervised learning.

Features

- Loads and explores the Iris dataset.
- Splits data into training and testing sets.
- Trains a K-Nearest Neighbors (KNN) classifier.
- Evaluates model accuracy.
- Predicts the class of a new flower.

Technologies

- Python
- Scikit-learn

Installation

python -m pip install scikit-learn

How to Run

python project2.py

Learning Outcomes

Dataset handling, data splitting, model training, classification, and model evaluation.
